# Story 9.9: Extract Dynamic Variables

## Status
Draft

## Story
**As a** pharmacy informaticist,
**I want** to extract variables from dynamic text sections automatically,
**so that** I can understand data dependencies and create comprehensive test cases

## Acceptance Criteria
1. Parse JavaScript code in dynamic sections to identify variables
2. Extract TPN calculation variables (getValue, hasValue calls)
3. Identify conditional logic and branching paths
4. Detect ingredient references and lookups
5. Show variable usage frequency and context
6. Support both simple and complex expressions
7. Generate variable dependency graph
8. Export extracted variables for test generation

### Data Models
**Variable Extraction Types** [New]
```typescript
interface ExtractedVariable {
  name: string;
  type: 'tpn' | 'ingredient' | 'calculated' | 'conditional';
  dataType: 'string' | 'number' | 'boolean' | 'object' | 'unknown';
  usage: VariableUsage[];
  required: boolean;
  defaultValue?: any;
  validationRules?: ValidationRule[];
  source: SourceLocation;
}

interface VariableUsage {
  line: number;
  column: number;
  context: 'read' | 'write' | 'condition' | 'calculation';
  expression: string;
  scope: string;
}

interface DependencyNode {
  variable: string;
  dependencies: string[];
  dependents: string[];
  depth: number;
  circular: boolean;
}

interface ExecutionPath {
  id: string;
  conditions: Condition[];
  variables: string[];
  probability?: number;
}

interface Condition {
  expression: string;
  variables: string[];
  type: 'if' | 'ternary' | 'switch' | 'logical';
  branches: {
    true: string[];
    false: string[];
  };
}
```

### AST Parsing Patterns
**Common TPN Patterns to Detect**:
```javascript
// getValue pattern
const value = getValue('calculatedValue');
const weight = getValue('patientWeight');

// hasValue pattern
if (hasValue('customDose')) { ... }

// maxP pattern
return maxP(calculated, 2);

// Ingredient lookup
const amino = ingredients.find(i => i.name.includes('Amino'));

// Conditional calculation
const dose = age < 18 ? pediatricDose : adultDose;
```

### Babel Configuration
```typescript
import { parse } from '@babel/parser';
import traverse from '@babel/traverse';

const ast = parse(code, {
  sourceType: 'module',
  plugins: ['jsx', 'typescript']
});

traverse(ast, {
  CallExpression(path) {
    // Detect getValue, hasValue calls
  },
  Identifier(path) {
    // Track variable references
  },
  ConditionalExpression(path) {
    // Analyze ternary operators
  }
});
```

### Variable Categories
**TPN Variables**: Patient data, calculations
- patientWeight, patientAge
- totalCalories, proteinRequirement

**Ingredient Variables**: Ingredient lookups
- aminoAcidConcentration
- dextroseVolume

**Calculated Variables**: Derived values
- totalVolume, osmolarity
- calciumPhosphateRatio

**Conditional Variables**: Logic control
- isNeonatal, hasCustomDose
- useAlternateFormula

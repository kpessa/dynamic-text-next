# Story 9.2: Create Ingredient Variants

## Status
Ready for Development

## Story
**As a** pharmacy informaticist,
**I want** to create new ingredient variants for different populations,
**so that** I can customize ingredient configurations for specific patient groups and health systems

## Acceptance Criteria
1. Provide a form to create new variants with population type and health system selection
2. Allow copying existing variant data as a starting point
3. Enable setting initial section content (both static and dynamic)
4. Enable setting initial test cases for the variant
5. Validate that required fields are populated before saving
6. Prevent duplicate variants (same ingredient + population + health system)
7. Auto-generate unique variant ID and set creation metadata
8. Show success confirmation and navigate to new variant after creation

## Dev Notes

### Previous Story Context
Story 9.1 established the IngredientVariantManager component and variantSlice for viewing variants. This story builds on that foundation by adding creation capabilities. The IngredientVariant interface and Firebase structure are already defined.

### Data Models
**IngredientVariant Interface** [Source: EPIC-9-CONFIG-MANAGEMENT.md, Story 9.1]
```typescript
interface IngredientVariant {
  id: string;                    // Generate UUID
  ingredientId: string;           // Parent ingredient reference
  ingredientType: 'Macronutrient' | 'Micronutrient' | 'Additive' | 'Salt' | 'Diluent' | 'Other';
  population: 'NEO' | 'CHILD' | 'ADOLESCENT' | 'ADULT';
  healthSystem: string;
  domain: string;
  subdomain: string;
  sections: {
    static: Section[];          // From parent project types
    dynamic: DynamicSection[];
  };
  tests: TestCase[];             // Test cases for this variant
  lastUpdated: Date;             // Set on creation
  validationStatus: ValidationStatus;
  syncStatus: 'synced' | 'conflict' | 'outdated' | 'unknown';
  version: string;
  createdBy?: string;            // User ID from auth
  createdAt?: Date;              // Creation timestamp
}
```

**Section Type** [Source: architecture/data-models.md]
```typescript
interface Section {
  id: string;
  type: 'html' | 'javascript';
  content: string;
  order: number;
  title?: string;
  description?: string;
  enabled?: boolean;
}
```

**TestCase Type** [Source: parent project models]
```typescript
interface TestCase {
  id: string;
  name: string;
  variables: Record<string, any>;
  expected?: string;
  description?: string;
  enabled?: boolean;
  tags?: string[];
}
```

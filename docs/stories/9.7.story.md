# Story 9.7: Export Domain Configurations

## Status
Draft

## Story
**As a** pharmacy informaticist,
**I want** to export configurations in domain-specific formats,
**so that** I can deploy updated configurations to different health systems in their required format

## Acceptance Criteria
1. Support export in multiple formats (JSON, CSV, Excel, XML, SQL)
2. Apply domain-specific transformations and naming conventions
3. Include only selected ingredients or export all
4. Generate export preview before download
5. Support custom export templates per domain
6. Add metadata and versioning information
7. Create deployment package with documentation
8. Track export history and recipients

### Data Models
**Export Types** [New]
```typescript
interface ExportConfiguration {
  id: string;
  domainId: string;
  format: 'json' | 'csv' | 'excel' | 'xml' | 'sql';
  template?: ExportTemplate;
  ingredients: ExportIngredient[];
  metadata: ExportMetadata;
  transformations: Transformation[];
}

interface ExportTemplate {
  id: string;
  name: string;
  domain: string;
  format: string;
  fields: FieldSelection[];
  formatting: FormatRules;
  version: string;
}

interface ExportIngredient {
  masterId: string;
  exportName: string; // After transformation
  exportData: Record<string, any>;
  included: boolean;
}

interface ExportMetadata {
  exportId: string;
  version: string;
  exportedAt: Date;
  exportedBy: string;
  sourceSystem: string;
  targetDomain: string;
  changesSince?: string; // Previous version
  checksum: string;
}

interface DeploymentPackage {
  mainFile: Blob;
  readme: string;
  changelog: string;
  rollbackScript?: string;
  validation: ValidationChecks;
}
```

### Export Format Specifications

**JSON Format**:
```json
{
  "metadata": {
    "version": "2.1.0",
    "exported": "2024-01-09T10:00:00Z",
    "domain": "health-system-east"
  },
  "ingredients": [
    {
      "id": "mapped-id",
      "name": "Amino Acid 10%",
      "concentration": 10,
      "unit": "percent"
    }
  ]
}
```

**SQL Format**:
```sql
-- Generated by TPN Config Manager v2.1.0
-- Domain: health-system-east
-- Exported: 2024-01-09 10:00:00

INSERT INTO ingredients (id, name, concentration, unit) VALUES
  ('mapped-id', 'Amino Acid 10%', 10, 'percent'),
  ...;
```

### Transformation Rules
**Domain-Specific Naming**:

const transformations = {

### File Size Considerations
- Warn if export >5MB
- Offer compression for files >10MB
- Stream large exports to avoid memory issues
- Show progress for exports taking >3 seconds

### Security Considerations
- Generate SHA-256 checksum for integrity
- Option to encrypt sensitive exports
- Audit log all export activities
- Sanitize data before export
- Remove internal IDs if configured

### Baseline Comparison Logic
```typescript
const compareWithBaseline = (current: TestResult[], baseline: TestResult[]) => {
  const regressions = current.filter(c => 
    c.status === 'fail' && 
    baseline.find(b => b.testCaseId === c.testCaseId)?.status === 'pass'
  );
  
  const improvements = current.filter(c =>
    c.status === 'pass' &&
    baseline.find(b => b.testCaseId === c.testCaseId)?.status === 'fail'
  );
  
  return { regressions, improvements };
};
```

### Analytics Metrics
1. **Test Stability**: (Passes / Total Runs) × 100
2. **Flakiness Score**: Inconsistent results frequency
3. **Coverage Impact**: Lines covered by test suite
4. **Execution Efficiency**: Tests per second
5. **Maintenance Burden**: Changes per month
6. **Health Score**: Composite of all metrics

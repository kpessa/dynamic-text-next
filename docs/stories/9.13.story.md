# Story 9.13: Compare Configurations

## Status
Draft

## Story
**As a** pharmacy informaticist,
**I want** to compare configurations and see color-coded differences,
**so that** I can quickly identify changes between domain configurations or versions

## Acceptance Criteria
1. Display side-by-side comparison of two configurations
2. Show color-coded differences (green=added, red=removed, yellow=modified)
3. Support unified diff view as alternative
4. Enable line-by-line and word-level diff granularity
5. Provide navigation between differences
6. Allow selection of specific sections to compare
7. Support comparison of multiple file formats
8. Export comparison results

### Data Models
**Comparison Types** [New]
```typescript
interface ConfigurationComparison {
  id: string;
  leftConfig: Configuration;
  rightConfig: Configuration;
  differences: Difference[];
  statistics: ComparisonStatistics;
  timestamp: Date;
  comparedBy: string;
}

interface Difference {
  type: 'added' | 'removed' | 'modified' | 'moved';
  path: string; // Location in configuration
  lineNumber?: number;
  leftValue?: any;
  rightValue?: any;
  context?: string[]; // Surrounding lines
  severity: 'major' | 'minor' | 'cosmetic';
}

interface ComparisonStatistics {
  totalDifferences: number;
  additions: number;
  deletions: number;
  modifications: number;
  moves: number;
  similarityScore: number; // 0-100%
}

interface DiffView {
  mode: 'side-by-side' | 'unified' | 'raw';
  granularity: 'line' | 'word' | 'character';
  ignoreWhitespace: boolean;
  ignoreCase: boolean;
  contextLines: number;
  syntaxHighlight: boolean;
}

interface DiffHighlight {
  startLine: number;
  endLine: number;
  startChar?: number;
  endChar?: number;
  type: 'add' | 'remove' | 'modify';
  color: string;
}
```

# Story 9.6: Map Imported Ingredients

## Status
Draft

## Story
**As a** pharmacy informaticist,
**I want** to map imported ingredients to my master ingredient database,
**so that** I can maintain consistency across domains and identify variations

## Acceptance Criteria
1. Display side-by-side comparison of imported vs master ingredients
2. Auto-match ingredients by name similarity (fuzzy matching)
3. Allow manual mapping for unmatched ingredients
4. Create new master ingredients from imported data
5. Show confidence scores for auto-matched items
6. Support bulk mapping actions (accept all suggestions)
7. Map test cases from imported ingredients to master ingredients
8. Track mapping history for audit purposes
9. Generate mapping conflict report

```typescript
interface IngredientMapping {
  id: string;
  importedIngredient: ConfigIngredient;
  masterIngredient?: MasterIngredient;
  mappingType: 'auto' | 'manual' | 'created';
  confidence: number; // 0-100
  status: 'pending' | 'accepted' | 'rejected';
  notes?: string;
  createdBy: string;

  configurationId: string; // Reference to import

interface MasterIngredient {
  id: string;
  name: string;
  code: string; // Unique identifier
  aliases: string[]; // Alternative names
  category: string;
  concentration?: string;
  unit?: string;
  variants: IngredientVariant[]; // From Story 9.1
  tests: TestCase[]; // Test cases for this master ingredient
}

interface TestCase {
  id: string;
  name: string;
  variables: Record<string, any>;
  expected?: string;
  description?: string;
  enabled?: boolean;
  tags?: string[];
}

interface MappingResult {
  totalImported: number;
  autoMatched: number;
  manuallyMapped: number;
  newMastersCreated: number;
  unmapped: number;
  testCasesMapped: number;
  conflicts: MappingConflict[];
}

interface MappingConflict {
  type: 'duplicate' | 'ambiguous' | 'contradiction';
  ingredients: string[];
  suggestion?: string;
}
```

### Fuzzy Matching Algorithm
**Matching Strategy**:
```typescript
// Composite score calculation
const calculateMatchScore = (imported, master) => {
  const nameScore = levenshteinSimilarity(imported.name, master.name) * 0.5;
  const aliasScore = checkAliases(imported.name, master.aliases) * 0.2;
  const concentrationScore = matchConcentration(imported, master) * 0.2;
  const categoryScore = matchCategory(imported, master) * 0.1;
  
  return (nameScore + aliasScore + concentrationScore + categoryScore) * 100;
};
```

### Confidence Thresholds
- **>90%**: Auto-accept mapping
- **70-90%**: Suggest for review
- **50-70%**: Show as possible match
- **<50%**: Require manual mapping

### UI/UX Patterns
**Visual Mapping Indicators**:
- 🟢 Green: High confidence (>90%)
- 🟡 Yellow: Medium confidence (70-90%)
- 🔴 Red: Low confidence (<70%)
- ⚫ Gray: Unmapped
- 🔗 Link icon: Manually mapped
